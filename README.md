# ATELIER NOIR

A modern, responsive architecture studio concept website.

## Overview

ATELIER NOIR is a front-end portfolio project featuring a fictional architecture and design studio.

## Features

- Responsive layouts for desktop and mobile
- Interactive project gallery and category filters
- Project detail views
- Smooth animations and transitions
- Minimalist, editorial-inspired design

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Type

Independent portfolio concept project.
